**複数のがん種でBasinNA群に女性が集中**。これは:
1. 女性のがん患者は男性と質的に異なる併存症プロファイルを持ち、男性中心に形成されるBasinパターンに当てはまらない
2. 女性のBasinNA患者は入院率が低い傾向があり、がんの治療アクセスや治療選択における性差を反映している可能性

→ **ジェンダー医学の観点から非常に興味深い知見。がん種横断的にこの傾向が確認されたのは新規。**

### がん種による Basin構造の多様性

- **1 Basin**: 胃がん、大腸がん、肺がん、膵がん、転移性がん → 均質
- **2 Basin**: 乳がん、前立腺がん → 軽い分化
- **3 Basin**: 血液悪性腫瘍、悪性腫瘍全般 → 中程度の分化
- **4 Basin**: 肝がん → 最も多様 → 肝がんの病態の多様性（肝硬変合併、ウイルス性、代謝性など）を反映

BasinNA含めると肝がんが4 Basinで最多。がんの中で最もheterogeneousな併存症構造。
